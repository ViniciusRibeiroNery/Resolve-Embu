## 2. Introdução

### 2.1 Objetivo do Projeto

O objetivo do "Resolve Embu" é registrar, mapear e analisar os problemas que são enfrentados pela população localizada na região do Embu das artes.

### 2.2 Problema Identificado

O problema é a falta do poder de fala dos cidadãos em registrar os problemas que são enfrentados no dia a dia nas ruas dos bairros, de maneira facil e pratica em um local onde todos tenham acesso.

### 2.3 Público-alvo

Todos cidadãos de Embu das artes e região.

## 3. Escopo do Sistema

### 3.1 Funcionalidades Incluídas

- Registrar problemas;
- Acessar problemas que já foram registrados;
- Status da situação do problema
- Mostrar um mapeamento dos principais problemas registrados.

### 3.2 Funcionalidades Não Incluídas

- Análise com os principais problemas que estão sendo registrados;
- Colocar localização com mapas;
- Colocar ideias de soluções;
- Colocar campo de comentário para atualizações dos problemas registrados.

## 4. Levantamento de Necessidades

### 4.1 Necessidades dos Usuários

- Poder Registrar os problemas;
- Poder ver os problemas registrados;
- ver status do problema.

### 4.2 Restrições Identificadas

- Bloquer registros "Trolls" com palavras inadequadas
